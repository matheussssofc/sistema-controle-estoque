# Sistema de Controle de Estoque

Projeto desenvolvido em Python para praticar conceitos básicos de programação através da criação de um sistema simples de controle de estoque.

## Sobre o projeto

O sistema permite cadastrar produtos, verificar produtos já cadastrados, listar os produtos e calcular o valor total do estoque.

O projeto foi desenvolvido com foco na prática de lógica de programação e nos fundamentos da linguagem Python.

## Funcionalidades

- Cadastro de produtos
- Verificação de código duplicado
- Validação de preço e quantidade
- Listagem dos produtos cadastrados
- Cálculo do valor total do estoque
- Menu interativo no terminal

## Tecnologias utilizadas

- Python

## Conceitos praticados

- Variáveis
- Listas
- Dicionários
- Funções
- Estruturas condicionais
- Estruturas de repetição
- Entrada de dados com `input()`
- Validação de informações
- Operações matemáticas
